
##  Сайт-портфолио команды

Веб-сайт, изображающий команду и её контактную информацию в наглядном виде, разработанный в рамках учебного проекта. 📋

## Цель проекта

Получить практические навыки командной разработки веб-сайта с использованием Git, GitHub и базовых веб-технологий.

## Функциональность

-  Отдельные страницы под каждого члена команды с контактной информацией
-  Музыкальное сопровождение
-  Переход к страницам членов команды кликом по их изображению
-  Отдельное меню навигации для быстрого перемещения по страницам сайта
-  Бот в соцсети Телеграмм для отправки потенциальных заявок о работе команде на Python-е

## Технологии

- HTML5 🛡
- CSS3 ⛰
- Python 🐍
- Git & GitHub 🐈‍

## Использование проекта

1. Клонируйте репозиторий: git clone https://github.com/Etglegion/team-practice-webportfolio.git
2. Откройте файл index.html в браузере.
